01

Overview

Damsel Nails is a nail studio in Egbeda, Lagos. The website shows the studio's services, pricing, gallery and reviews, and gives clients a way to get in touch and book.

Appointments are handled by a separate app I built for the studio — see Damsel Booking.

02

Version 1 → Version 2

Version 1 was a one-page landing page to showcase the services and gallery images. I used the Bootstrap grid for a responsive image gallery, and JavaScript to change the theme background colour.

Version 2 is a full rebuild: separate Home, About, Services, Gallery and Contact pages, with a black, white and champagne editorial look and a centred, cinematic hero used across the site.

03

Key features

  • Multi-page site: Home, About, Services, Gallery, Contact and a privacy policy page.
  • Image carousels built with Swiper.js, and animated service images.
  • An image admin backed by Supabase, so gallery and site images can be changed without editing code.
  • An AI support chatbot connected to an n8n webhook.
  • A contact form sent through an n8n automation that shows the real send status to the visitor.
  • SEO basics: sitemap, robots.txt, canonical URLs and local business schema.
