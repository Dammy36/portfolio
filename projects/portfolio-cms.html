Overview

A personal portfolio built with React, Vite and Tailwind CSS, backed by Supabase (Postgres, Auth and Storage). All of the content lives in the database, and a private /admin dashboard lets me manage it without changing any code.

02

Key features

  • Public site with About, Services, Skills, Projects, Certifications and Contact sections.
  • Individual case study pages for each project.
  • Admin dashboard with editors for About, Services, Skills, Projects, Certifications, Contact and site settings.
  • Login with Supabase Auth, including a password-reset flow.
  • Images uploaded to Supabase Storage, with Row Level Security policies on the database.
