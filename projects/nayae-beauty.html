Overview

A React e-commerce and booking website for Nayaé Beauty, backed by Supabase for the database, admin login and file storage. Visitors can shop makeup products or book a beauty service from the same site.

02

Key features

  • Shop with product pages, a cart and checkout, plus an “Added to cart” confirmation toast.
  • Services pages, service details and an appointment booking form.
  • Checkout collects the customer's WhatsApp number and prepares an order message for WhatsApp.
  • Admin area with login: dashboard, product management, and orders and bookings with status filter tabs.
  • SEO basics: per-page titles, meta tags and structured data.
  • Scroll-reveal animations on the pages.
